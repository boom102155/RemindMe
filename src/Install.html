Remind Me

ระบบจัดการภารกิจ รายรับ-รายจ่าย
และการแจ้งเตือนผ่าน LINE Bot

✅ ระบบจะสร้าง Google Sheet ใหม่ ใน Drive ของคุณ
✅ สร้างชีตและค่าเริ่มต้นทั้งหมดอัตโนมัติ
✅ ข้อมูลทั้งหมดเป็นของคุณ ไม่มีข้อมูลของใครติดมา
✅ ไม่ต้องแก้ไข Spreadsheet ID ในโค้ด

การติดตั้งจะสร้าง Spreadsheet ชื่อ "Remind Me"
และบันทึก Spreadsheet ID ไว้ใน Script Properties โดยอัตโนมัติ

✓

ติดตั้งระบบเรียบร้อยแล้ว

ระบบสร้าง Google Sheet ฐานข้อมูลของคุณเรียบร้อยแล้ว
ตอนนี้คุณสามารถเริ่มใช้งาน Remind Me ได้ทันที

เข้าสู่ระบบ Remind Me เปิดฐานข้อมูล (Google Sheet)

ขั้นตอนต่อไป: ไปที่หน้า "ตั้งค่า" เพื่อเชื่อมต่อ LINE Bot
(ใส่ Channel Access Token, User ID และลิงก์ Dashboard)
