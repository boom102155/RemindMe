การตั้งค่าครั้งแรก

หากคุณเพิ่ง Copy ระบบนี้มา ให้ทำตามขั้นตอนด้านล่าง

  1. Deploy โปรเจกต์นี้เป็น Web App (ใช้ Execute as: Me, Access: Anyone)
  2. กดปุ่ม “ตั้งค่าเริ่มต้นระบบ” เพื่อสร้าง Sheet และหมวดหมู่เริ่มต้น
  3. นำ Web App URL มาใส่ในขั้นตอน “เชื่อมต่อ LINE”
  4. ใส่ LINE Channel Access Token และ User ID
  5. นำ Url ของระบบมาใส่ในช่อง "ลิงก์ Dashboard (Web App URL)" ตั้งเวลาเริ่มต้น Trigger เป็น "ตรงเวลา" จากนั้นกด "เปิด Trigger" และกด "บันทึกการตั้งค่า LINE" และกด "ทดสอบ LINE" หากส่งสำเร็จจะมีข้อความแจ้งเตือนไปยัง Line Bot
  6. หากต้องการดึง Line Bot เข้ากลุ่มให้ไปตั้งค่าการอนุญาตใน Line Messaging API เมื่อดึงบอทเข้ากลุ่มระบบจะเพิ่มรายการกลุ่มอัตโนมัติ
  7. สามารถ เพิ่ม ลบ แก้ไข ข้อมูลหมวดหมู่ได้ในหน้านี้จากแถบ หมวดหมู่ ด้านบน
  8. การทำ Rich Menu ใช้ขนาดของภาพตามที่ Line กำหนด (2500 x 1686 px) และนำภาพไปใส่ไว้ใน Drive จากนั้นนำ Id ของภาพมาใส่ในช่อง "Google Drive File ID รูป Rich Menu" ในแถบ Rich Menu ด้านบน จากนั้นกดปุ่ม "สร้างและตั้งค่า Rich Menu"
